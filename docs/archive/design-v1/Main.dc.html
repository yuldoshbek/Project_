Принцип 01
Цвет — носитель смысла
Он кодирует состояние проекта, приоритет задачи и зону риска по сроку. Прямые значения цвета в компонентах запрещены — только переменные.
Принцип 02
Цвет считает сервер
Светофор приходит из API одним правилом для проекта и задачи. Вычислять его в интерфейсе — значит развести дашборд и списки в оценке одной записи.
Принцип 03
Цвет никогда не один
У каждого цветового признака есть подпись или значок: цвет сам по себе не читается программой чтения с экрана и теряется при печати.

Шкала описывает текст. Кроме неё в системе есть три служебные ступени, и они тоже правило, а не самодеятельность: 15px — заголовок карточки в плотной сетке, 13px и 11.5px — строки списков на телефоне, 26px — крупная цифра показателя, у которой line-height: 1. Ниже 11px не опускается ничто.
