# Архив: документы объёма до 18.09.2026

Здесь лежат документы, описывавшие ORBITA до сужения объёма с девяти разделов ТЗ до трёх
блоков ([PLAN](../PLAN.md), [CONTEXT](../CONTEXT.md)). **Ни один из них больше не
действует.** Они оставлены целиком и без правок по трём причинам.

Первая: они объясняют, почему в схеме есть поля, которых новый объём не требует —
`tasks.is_control`, `planned_due_at`, `external_seta_id`, `share_externally`. Эти поля не
удалены намеренно: они нужны третьему блоку. Без архива через месяц никто не отличит
«оставлено умышленно» от «забыли убрать».

Вторая: приёмка. Заказчик утверждал ТЗ v1.0, и сравнивать будут с ним — **Q17** в
[OPEN-QUESTIONS](../OPEN-QUESTIONS.md) остаётся самым дорогим открытым вопросом проекта.
Пока ТЗ v2.0 не подписано, эти файлы показывают, что именно снято и когда.

Третья: 21 закрытая карточка — это написанный и проверенный код, который переворот пережил
целиком. Их критерии приёмки живут здесь.

| Файл | Что это | Заменён на |
|---|---|---|
| `SPEC-v1.md` | Спецификация девяти разделов, 695 строк | Пока — [PLAN.md](../PLAN.md); SPEC v2 пишется командой `/to-spec` от плана |
| `STATE-2026-09-17.md` | Снимок состояния работ на 17.09.2026: 21 закрытая карточка из 98, 40 очков из 120 | Пересобирается заново после нарезки новых тикетов |
| `tickets/INDEX.md` и `tickets/E0…E7` | 98 карточек прежнего объёма | [tickets/INDEX.md](../tickets/INDEX.md) |

**Решения (ADR) в архив не переезжают.** Отменённая запись помечается статусом
«ОТМЕНЁН» и остаётся в `docs/adr/`: решение, вычеркнутое из истории, перестаёт объяснять,
почему когда-то поступили иначе. Отменены 18.09.2026: ADR-0012 (Google), ADR-0017
(корреспонденция), ADR-0018 (встречи), ADR-0022 (ИИ-слой), ADR-0023 (Ижро как вид
обращения). ADR-0020 действует наполовину, ADR-0021 пересмотрен под three.js.
