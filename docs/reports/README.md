# Отчёты блоков

Здесь лежат итоговые отчёты по блокам работ плана: [BLOCK-0](BLOCK-0.md),
[BLOCK-1](BLOCK-1.md), [BLOCK-2](BLOCK-2.md), [BLOCK-3](BLOCK-3.md). Состав отчёта задан
командой [`/report`](../../.claude/commands/report.md): что сделано, критерии приёмки с
доказательствами, тест визуала со снимками, тест кода, ограничения, что посмотреть
заказчику, влияние на план.

Отчёт пишется до приёмки и не переписывается после неё: замечания заказчика и правки
попадают в отчёт следующего блока или в [журнал изменений плана](../PLAN.md).

Снимки экранов и PDF лежат в папке своего блока: `block-0/` … `block-3/`. Их делают
сценарии Playwright (`frontend/e2e`) — папка задаётся переменной `ORBITA_E2E_BLOCK`, чтобы
снимки нового блока не затирали доказательства прошлого. Без переменной снимки
пишутся в `block-3/`, папку последнего блока плана (`frontend/e2e/link.ts`), поэтому прогон
без своей папки перезаписывает в рабочей копии доказательства блока 3.
