# Отчёты блоков

Здесь лежат итоговые отчёты по блокам работ: `BLOCK-0.md`, `BLOCK-1.md` и так далее.
Состав отчёта задан командой [`/report`](../../.claude/commands/report.md): что сделано,
критерии приёмки с доказательствами, тест визуала со снимками, тест кода, ограничения, что
посмотреть заказчику, влияние на план.

Отчёт пишется до приёмки и не переписывается после неё: замечания заказчика и правки
попадают в отчёт следующего блока или в [журнал изменений плана](../PLAN.md).
