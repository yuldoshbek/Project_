# Открытые вопросы к заказчику

Правило: пока ответа нет, работает зафиксированное допущение. Если реализация упирается в
неотвеченный вопрос — не угадывать, а дописать вопрос сюда и реализовать по допущению.

| # | Вопрос | Кому | Допущение до ответа | Блокирует |
|---|---|---|---|---|
| Q1 | Пороги «светофора»: с какого момента проект жёлтый? | Заказчик | 3 дня до срока либо израсходовано 80% времени ([ADR-0005](adr/ADR-0005-traffic-light.md)) | ORB-029 (оценка), не разработку |
| Q2 | Вариант A или B утверждается официально? Есть ли доступ к репозиторию SETA и к плану её команды? | Заказчик + команда SETA | Работаем по [ADR-0001](adr/ADR-0001-architecture-variant.md) («A-ready») | ORB-041, ORB-046 |
| Q3 | Образцы бланков отчётов Word и Excel, принятых в документообороте агентства | Аппарат зам. директора | Универсальный шаблон: шапка, таблица, подпись | ORB-043 — оценка недостоверна без образцов |
| Q4 | Кто «вышестоящее лицо» для эскалации по умолчанию и через сколько часов каждый уровень? | Заказчик | куратор → помощник (через 24 ч) → руководитель ([ADR-0008](adr/ADR-0008-notifications-escalation.md)) | нет |
| Q5 | Есть ли в агентстве каталог пользователей (Active Directory, LDAP, ведомственный SSO)? | IT-служба | Локальные учётные записи + пароль, смена при первом входе | ORB-006 (объём) |
| Q6 | Подтверждение, что «Просрочена» — признак, а не статус ([ADR-0004](adr/ADR-0004-overdue-is-computed.md)) | Заказчик | Реализуем как признак | нет |
| Q7 | Предельный размер вложения, белый список типов файлов, требуется ли антивирус | IT-служба + СБ | 50 МБ, офисные форматы и изображения, ClamAV включён | ORB-017 |
| Q8 | Язык интерфейса по умолчанию и порядок сортировки для узбекской латиницы | Заказчик | По умолчанию русский, переключатель в профиле | ORB-048 |
| Q9 | Площадка размещения (ЦОД, требования локализации данных) | IT-служба | Разработка ведётся в docker-compose, продовый контур — позже | ORB-047, ORB-050 |
| Q10 | Когда ожидается заключение СБ по классификации данных мониторинга | СБ агентства | Режим `restricted` заложен в MVP ([ADR-0007](adr/ADR-0007-restricted-data.md)) | перенос реальных проектов, не разработку |
| Q11 | Кто утверждает внутренний регламент обязательного ведения проектов в системе (ТЗ 15) | Заказчик | Считаем условием приёмки этапа 3 | внедрение |
| Q12 | Нужен ли учёт рабочего времени и трудозатрат по задачам | Заказчик | Не делаем: в ТЗ не заявлено | нет |
| Q13 | Требуется ли корпоративная почта как отправитель (SMTP-реквизиты) и с какого адреса | IT-служба | MailHog в dev, реквизиты продового SMTP — параметр | ORB-040 |
| Q14 | Сколько сотрудников заводится на старте и какова структура подразделений | Заказчик | 60 пользователей, плоская структура + справочник подразделений | ORB-007 (сиды) |
