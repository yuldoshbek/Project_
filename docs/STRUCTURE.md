# Структура репозитория

Каждый каталог отвечает на один вопрос. Если файл не находит себе места в этом описании —
скорее всего, он лежит не там.

Состояние на 10.09.2026: 19 архитектурных решений, 80 карточек тикетов в семи эпиках,
4 миграции, 127 тестов backend и 26 frontend.

## Где живут данные

Данные приложения не лежат в репозитории **нигде** и никогда туда не попадают.

| Что | Где живёт | Как пережить перезапуск |
|---|---|---|
| Проекты, задачи, справочники, аудит | PostgreSQL, схема `orbita`, том Docker `orbita_postgres-data` | `make down` сохраняет, `make reset` удаляет |
| Тестовые данные | отдельная база `orbita_test` в том же контейнере | пересоздаётся прогоном тестов |
| Очередь фоновых задач | Redis, том `orbita_redis-data` | потеря очереди не теряет данных: задания идемпотентны (ADR-0008) |
| Вложения к проектам и задачам | S3-совместимое хранилище, бакет `orbita`; в разработке MinIO, том `orbita_minio-data` | `make reset` удаляет |
| Письма разработки | Mailpit, только в памяти | наружу не уходят никогда |
| Секреты | `.env` локально, GitHub Secrets в CI | в репозиторий не попадают: он публичный |

**Схема базы меняется только миграцией Alembic.** `create_all` в рантайме запрещён:
расхождение схемы разработки и рабочей обнаруживается тогда, когда чинить дороже всего.

**Токены обновления Google хранятся зашифрованными** ключом, который не входит в
резервную копию базы: копия базы в чужих руках не должна давать доступ к календарю
руководителя.

## Правила размещения

**Границы слоёв backend.** Зависимости идут только вниз:
`api → workers → services → adapters → repos → domain`. Обратные импорты запрещены и
проверяются `import-linter` (контракты в `backend/pyproject.toml`, тест —
`backend/tests/test_import_contracts.py`). Тест намеренно вносит нарушение и убеждается,
что оно поймано: контракт, который ничего не ловит, хуже отсутствующего.

`adapters` стоит **над** `repos`, а не рядом: адаптер внешней системы почти всегда
работает с данными — провайдер входа сверяет пароль с хешем в базе. Обратное запрещено и
остаётся запрещённым: репозиторий не имеет права звонить в Telegram.

**Где чему не место.**

| Не кладите | Кладите |
|---|---|
| SQL в роутере или сервисе | `backend/app/repos/` |
| Бизнес-правило в компоненте React | `backend/app/domain/`, наружу — через API |
| Текстовую строку в компоненте | словарь локализации, три письменности |
| Вызов S3 или SMTP напрямую | адаптер за портом в `backend/app/adapters/` |
| Изменение схемы БД в коде | миграция Alembic |
| Значение цвета в компоненте | `frontend/src/styles/tokens.css` |
| Реальные данные агентства, `.env`, дампы | нигде в репозитории |

**Документы и код расходятся — это дефект.** Если реализация отклонилась от ADR, обновите
ADR или заведите новый со статусом «заменяет ADR-NNNN». Если требование ТЗ понято иначе,
чем написано, — это строка в `docs/OPEN-QUESTIONS.md`, а не молчаливое допущение в коде.

**Каталог `tz/` только для чтения.** Разработка не правит техническое задание. Замечания к
нему собираются в `docs/council/COUNCIL-0001.md`, раздел «Что предлагается изменить в ТЗ».
