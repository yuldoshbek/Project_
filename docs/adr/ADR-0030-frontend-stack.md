# ADR-0030. Стек интерфейса: React 19, Tailwind, shadcn/ui, Motion, Recharts

- Статус: принято · Дата: 20.09.2026 · Контекст: видение заказчика 19.09.2026 — «сайт с
  анимацией и красивыми данными, тема космос», мобильная версия главная
- **Заменяет** [ADR-0002](ADR-0002-tech-stack.md) в части фронтенда и отменяет §6
  [ADR-0021](ADR-0021-cosmic-visual-layer.md) («библиотеки графиков не будет»)
- Связано: [ADR-0028](ADR-0028-hosting.md)

## Контекст

Прежний интерфейс — React 18 на CSS Modules, без компонентного слоя: пять стилей кнопок,
продублированные поля, эталон дизайна разошёлся с кодом на следующий день. Новый объём
требует графиков, диаграммы Ганта, канбана, интеллект-карты и трёх разных раскладок под
телефон, ноутбук и монитор.

Проверка показала: фронтенд SETA (React 18 без роутера и библиотек, Mini App собран, но не
включён) ничего нам не диктует — прежний довод «стек выбран под совместимость с SETA»
отпал.

## Решение

| Что | Чем | Почему |
|---|---|---|
| Основа | React 19, TypeScript, Vite | точная версия под R3F; сборка без сюрпризов |
| Стили и токены | Tailwind CSS 4, токены в CSS-переменных | одна точка правды для двух тем, счётная проверка контраста |
| Компоненты | shadcn/ui | код внутри проекта, а не зависимость; доступность из коробки |
| Движение | Motion, режим `reducedMotion="user"` | анимация объясняет изменение, а не украшает |
| Графики | Recharts | построен на тех же токенах, что shadcn; данных сотни строк, мощность ECharts не нужна |
| Гантт, трасса, орбиты | свой SVG на d3-scale | ни одна библиотека Ганта не даёт нужного вида и лицензии |
| Значки | Lucide | один набор вместо ручной разметки |
| Данные и маршруты | TanStack Query и Router | опрос, кеш, инвалидация, типобезопасные маршруты |
| Клиент API | генерируется из OpenAPI | контракт не расходится с бэкендом |
| Языки | react-i18next | три письменности, ни одной строки в коде |
| Телефон | PWA: установка на экран «Домой», уведомления | магазины приложений не нужны |
| Трёхмерность | React Three Fiber, отдельным чанком, вне телефона | сохраняется ограничение ADR-0021 §3а |

Тем две: светлая основная и приглушённая сланцево-синяя. Тёмная «ЦУП» из ADR-0021 больше
не основная — заказчик попросил светлую и «не очень тёмную».

## Отвергнутые варианты

- **Остаться на CSS Modules.** Дешевле сегодня, но компонентного слоя так и не появится, а
  два способа стилизации рядом — известный источник расхождений.
- **ECharts.** Мощнее и тяжелее; темизация мимо токенов ломает счётную проверку контраста,
  ради которой §6 ADR-0021 и запрещал библиотеки.
- **Готовая библиотека Ганта.** Лицензии или вид, который придётся переопределять целиком.

## Последствия

- Интерфейс пишется заново: перенести из старого можно около 600 строк инфраструктуры.
- Появляется бюджет размера: начальный JS не больше 250 КБ в сжатом виде, проверяется в CI.
- Токены — единственный источник цвета; цвет в компонентах не пишется руками.
