переписывать прошлый.

## Правила параллельной работы

1. Один тикет — одна ветка — один worktree: `orb-101-ijro-schema`.
2. Коммит: `ORB-101: краткое описание в повелительном наклонении`.
3. Между тикетами — `/clear`. Контекст предыдущего мешает следующему.
4. Карточки одной волны берутся параллельно, если между ними нет стрелки зависимости.
5. **Закрыт — это прошедший `/verify` и `/code-review`**, а не «написан код».
6. Миграции пишутся по одной на карточку и держат одну голову.

## Критический путь

```
0 ──► A ──► B ──► C ──► D
      └──► S
V1 ──► V2        (параллельно A и B, сходятся с C на экранах)
```

**Первая точка, где заказчику есть что показать, — конец волны B.**
