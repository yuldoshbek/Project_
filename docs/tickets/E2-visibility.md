# Эпик E2 — Видимость: календарь, дашборд, справочники, поиск

Этап 2 ТЗ. Результат — полноценный визуальный контроль, ради которого систему заказывали.

---

## ORB-026 — Календарь: события и единая лента

- Оценка: M · Зависит от: ORB-012, ORB-014 · Блокирует: ORB-027, ORB-028
- Требования ТЗ: 6.3

**Объём.** `calendar_events`, `event_participants`, эндпоинт `GET /calendar`,
собирающий три источника: вехи проектов, сроки задач, встречи. Фильтры по типу, проекту,
исполнителю. Учёт `visible_projects`.

**Критерии приёмки.**
- [ ] Один запрос отдаёт события всех трёх типов за период, каждое с типом и приоритетом.
- [ ] Чужие проекты в ленту не попадают.
- [ ] Запрос за месяц с 3000 задач выполняется не дольше 300 мс.

## ORB-029 — Дашборд: агрегаты и светофор

- Оценка: L · Зависит от: ORB-011, ORB-014 · Блокирует: ORB-030, ORB-031, ORB-032
- Требования ТЗ: 6.4 · Решения: ADR-0005 · Открытый вопрос: Q1

**Объём.** Один эндпоинт `GET /dashboard`, отдающий все показатели ТЗ 6.4: проекты по
статусам, число просроченных задач, нагрузка по исполнителям, задачи по приоритетам,
распределение по светофору. Фильтры: направление, куратор, период.

**Критерии приёмки.**
- [ ] Все показатели считаются одним SQL-запросом (или CTE-набором), без N+1.
- [ ] p95 не более 400 мс на наборе 200 проектов и 3000 задач.
- [ ] Правило светофора совпадает с ADR-0005; Python- и SQL-реализации дают один результат на общем наборе.
- [ ] Показатели считаются только по видимым актору проектам.

## ORB-032 — Вид помощника «Сегодня»

- Оценка: M · Зависит от: ORB-029 · Требования ТЗ: 3.3, 6.4, сценарий U2

**Цель.** Ключевой экран системы. Не «мои задачи», а весь периметр руководителя.

**Объём.** `GET /assistant/today` — сгруппированный список: просрочено; горит сегодня и
завтра; ожидает решения руководителя (статус «На контроле руководителя»); проекты,
свалившиеся в красную зону со вчерашнего дня; задачи без исполнителя или без срока.

**Критерии приёмки.**
- [ ] Помощник видит записи по всем проектам периметра, а не только по своим.
- [ ] Каждая группа даёт переход в отфильтрованный список одним кликом.
- [ ] Экран открывается за один запрос и не требует прокрутки для оценки ситуации.
- [ ] Проекты `restricted`, куда помощник не включён, не показываются даже счётчиком.

## ORB-033 — Глобальный поиск

- Оценка: L · Зависит от: ORB-011, ORB-014, ORB-016, ORB-017 · Блокирует: ORB-034
- Требования ТЗ: 6.9, 10.3 · Решения: ADR-0006, ADR-0007

**Объём.** Функция `normalize_search`, генерируемые `search_vector`, GIN-индексы,
триграммный индекс, ранжирование, фоновое извлечение текста из вложений.

**Критерии приёмки.**
- [ ] Запрос на узбекской латинице находит запись, введённую на узбекской кириллице, и наоборот.
- [ ] Запрос с опечаткой в одном символе находит запись (триграммы).
- [ ] Поиск по названию организации-партнёра возвращает связанные проекты, задачи и файлы (сценарий U6).
- [ ] Записи `restricted`-проектов исключаются до подсчёта результатов, а не после.
- [ ] Табличный тест транслитерации на реальных названиях из справочника зелёный.

## ORB-035 — Администрирование справочников

- Оценка: M · Зависит от: ORB-010, ORB-008 · Требования ТЗ: 6.8

**Критерии приёмки.**
- [ ] Направления, приоритеты, статусы и настройки редактируются в интерфейсе без разработчика.
