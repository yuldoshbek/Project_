# data/ — настоящие данные агентства

**Содержимое этой папки в git не попадает** (кроме этого файла). Репозиторий публичный, а
в контрольных таблицах «Ижро» — поручения Администрации Президента и Кабинета Министров с
фамилиями ответственных сотрудников.

## Что сюда кладётся

```
data/ijro/     контрольные таблицы «Назорат жадвали» и разбор проблемных поручений (.docx)
```

Четыре файла, по которым спроектирован раздел «Ижро» ([ADR-0025](../docs/adr/ADR-0025-ijro-standalone-register.md),
[PLAN](../docs/PLAN.md)):

## Почему тесты строятся не на них

CI этих файлов не видит и видеть не должен. Тесты разборщика идут на **обезличенных
образцах**: таблицу собирает в памяти `backend/tests/docx_builder.py` — та же разметка,
вымышленные номера документов и фамилии. Расхождение образцов с настоящими файлами —
названный риск: тесты остаются зелёными, а ввоз ломается. Поэтому при каждом изменении
разборщика прогон делается дважды — на образцах в CI и на настоящих файлах руками. На
08.10.2026 разборщик проверен только на образцах ([HANDOFF](../docs/HANDOFF.md),
раздел 11).

В рабочий контур таблицы попадают не из этой папки, а загрузкой помощника: раздел «Ижро»,
вкладка «Загрузка».

## Если папка пуста

Значит вы работаете на чужой машине. Файлы присылает заказчик; без них раздел «Ижро» можно
разрабатывать по образцам, но принимать — нельзя.
