# data/ — настоящие данные агентства

**Содержимое этой папки в git не попадает** (кроме этого файла). Репозиторий публичный, а
в контрольных таблицах «Ижро» — поручения Администрации Президента и Кабинета Министров с
фамилиями ответственных сотрудников.

## Что сюда кладётся

```
data/ijro/     контрольные таблицы «Назорат жадвали» и разбор проблемных поручений (.docx)
```

Четыре файла, по которым спроектирован блок «Ижро» ([ADR-0025](../docs/adr/ADR-0025-ijro-standalone-register.md),
[PLAN](../docs/PLAN.md)):

| Файл | Что это | Строк |
|---|---|---|
| `1. ПА Назорат жадвали 2026 йил.docx` | фармойиш и резолюции руководителя Администрации Президента | 11 |
| `1. ВМнинг Назорат жадвали 2026 йил.docx` | постановления Кабинета Министров | 39 |
| `1. АПП назорат жадвали (2026 й.).docx` | законодательные акты: ПФ, ПҚ, ЎРҚ, Баён | 115 |
| `Проблема_бўлиши_мумкин_бўлган_топшириқлар_11_09.docx` | поручения с высоким риском срыва: `Муаммо` + `Таклиф` | 5 |

## Почему тесты строятся не на них

CI этих файлов не видит и видеть не должен. Тесты разборщика идут на **обезличенных
образцах** в `backend/tests/samples/ijro/`: та же структура, вымышленные номера документов
и фамилии. Расхождение образцов с настоящими файлами — назван­ный риск
([PLAN](../docs/PLAN.md), риск 3): тесты остаются зелёными, а ввоз ломается. Поэтому при
каждом изменении разборщика прогон делается дважды — на образцах в CI и на настоящих
файлах руками.

## Если папка пуста

Значит вы работаете на чужой машине. Файлы присылает заказчик; без них блок «Ижро» можно
разрабатывать по образцам, но принимать — нельзя.
