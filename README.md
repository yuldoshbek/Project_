# ORBITA

Рабочее пространство аппарата заместителя директора Агентства космических исследований и
технологий «Ўзбеккосмос». Пользователей двое: помощник вносит данные, заместитель
директора смотрит с iPhone и принимает решения.

Система отвечает руководителю на один вопрос: **что требует моего внимания сейчас и какое
решение я принимаю**. Всё остальное подчинено двум свойствам: картина читается за полминуты
с телефона, а ввод стоит секунды — что можно вычислить, вычисляется.

## Разделы

| Раздел | Вопрос |
|---|---|
| Пульт | что требует внимания сейчас по всем разделам |
| Программы | где мы по многолетним программам и что должно случиться до конца года |
| Проекты | где мы по каждому проекту и подпроекту |
| Задачи | что делать, кому и к какому сроку |
| Ижро | что на контроле, что горит, работает ли ответственный, из-за кого сорвётся |
| Взаимодействие | кто кого ждёт: организации, письма, соглашения |
| Доклады и мероприятия | готовы ли мы к дате и кто задерживает |
| Идеи и карты | что предложено и как это связано |
| Календарь | что и когда наступит, где тесно |
| Управление | справочники, загрузка Ижро, обход, ссылки доступа |

## Запуск

```bash
make up            # postgres для разработки
make migrate       # схема
make seed          # справочники и демо-данные
make dev           # backend :8000, frontend :5173
make test          # pytest + vitest
make e2e           # playwright
make check         # ruff + mypy + import-linter + eslint + prettier + tsc
```

На Windows: `./make.ps1 <цель>`.

## Как идёт работа

Крупными блоками: один блок — одна ветка — один PR. В каждом блоке четыре шага:
разработка → тест визуала → тест кода → отчёт. Потом приёмка заказчиком на превью и
выкладка в рабочий контур по кнопке. Объём блока не меняется посреди блока.

Состояние: идёт **блок 0 — подготовка** (документы, конвейер, каркас).

## Размещение

Сейчас: интерфейс на Netlify, API на Vercel, PostgreSQL и файлы — в облаке; каждое
изменение получает превью со своей копией демо-данных. Позже система переезжает на сервер
агентства тем же конвейером: внешний мир спрятан за портами, код не меняется.
