# ORBITA

Система управления проектами и задачами Агентства космических исследований и технологий
Республики Узбекистан («Ўзбеккосмос»). Внутреннее веб-приложение: портфель проектов,
база задач, календарь, дашборд со «светофором» по срокам, уведомления и эскалация,
отчётность.

Статус: **проектирование завершено, разработка не начата.** Кодовая база создаётся
потикетно, начиная с ORB-001.

## Ключевые решения одной строкой

- **Своя разработка, не коробочный продукт** — уникальная часть (вид помощника
  руководителя, связка с SETA, три письменности в поиске) и есть предмет заказа.
- **Не A и не B, а «A-ready»** ([ADR-0001](docs/adr/ADR-0001-architecture-variant.md)):
  самостоятельный сервис, спроектированный под слияние с SETA; интеграция включается
  настройкой, а не переписыванием.
- **Права считаются на уровне проекта** ([ADR-0003](docs/adr/ADR-0003-project-level-rbac.md)) —
  это определяет форму каждого запроса и не добавляется задним числом.
- **Режим данных ограниченного доступа заложен в MVP**
  ([ADR-0007](docs/adr/ADR-0007-restricted-data.md)), не отложен до заключения СБ.

## Стек

Python 3.12 / FastAPI / PostgreSQL 16 / Redis + ARQ · React 18 + TypeScript / Vite ·
S3-совместимое хранилище файлов. Обоснование —
[ADR-0002](docs/adr/ADR-0002-tech-stack.md).

```bash
git worktree add -b orb-001-tooling /d/orbita-wt/orb-001 main
```

Команды `make up`, `make dev`, `make test` появятся в результате ORB-001 и ORB-002 —
сейчас их ещё нет, и это ожидаемо.
