# Проверка блока $ARGUMENTS

«Написал код» — не признак готовности. Готовность — это выполненные критерии приёмки,
подтверждённые запуском. Порядок обязательный, пункт без выполнения не отмечается.

## 1. Запусти, а не предположи

```bash
make check
make test
make e2e
```

Приложи фактический вывод. Если что-то падает — скажи прямо, с выводом. Красный тест,
объявленный «не связанным с моими изменениями», подтверждается: покажи, что он падал и до
них.

## 2. Пройди критерии приёмки блока по одному

Открой карточку блока в [PLAN](../../docs/PLAN.md). По каждому критерию назови, **чем
именно** он подтверждён: имя теста или описание ручной проверки с результатом.

## 3. Проверь визуал

Снимки телефона, ноутбука и монитора в обеих темах. Приложи пути к снимкам.

## 4. Проверь инварианты

- цифры на Пульте и в разделе считает один сервис — подтверждено тестом;
- «что если» ничего не пишет в базу;
- каждое изменение попало в журнал;
- фоновая задача при повторном запуске не сделала работу дважды;
- реальных данных в превью нет.

## 5. Отчитайся тремя списками

**Работает** (с доказательством) · **Не работает** (с выводом) · **Не проверено** (почему).

Пустой второй и третий список без доказательств первого — это не отчёт.
