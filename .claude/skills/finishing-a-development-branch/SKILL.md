# Завершение ветки

Ветка закончена не тогда, когда код написан, а тогда, когда он слит, дерево убрано, а
документация отражает то, что получилось.

## Предусловия

Не начинай, пока не выполнено:
- `/verify` пройден, фактический вывод тестов есть;
- `/code-review` пройден, замечания исправлены или отклонены с обоснованием;
- все чекбоксы критериев приёмки отмечены и подтверждены.

## Порядок

**1. История.** `git log --oneline main..HEAD`. Коммиты в формате
`ORB-NNN: краткое описание`. Мусорные коммиты склей. Историю уже забранной кем-то ветки не
переписывай.

**2. Синхронизация.**
```bash
git fetch origin && git rebase origin/main
make check && make test
```
Перепрогон обязателен: rebase меняет код вокруг твоего.

**3. Головы Alembic.** После rebase:
```bash
alembic heads
```
Головы должно быть **одна**. Две означают, что в `main` появилась миграция параллельно с
твоей: перебазируй свою на актуальную (`down_revision` на новую голову) и прогони
`upgrade head` с `downgrade` на чистой базе. Не «чинить» это правкой таблицы
`alembic_version` в БД.

**4. Слияние — действие наружу.** Спроси человека перед `push` и открытием PR.
Описание PR: что делает тикет, какие критерии приёмки закрыты, что осталось за границами,
какие ADR затронуты, какие вопросы к заказчику всплыли.

**5. Уборка.**
```bash
git worktree remove /d/orbita-wt/orb-NNN
git branch -d orb-NNN-слаг
git worktree prune
```

**6. Документация.** Проверь, что отражено:
- тикет отмечен закрытым в `docs/tickets/`;
- новые вопросы — в `docs/OPEN-QUESTIONS.md`;
- отклонение от решения — новый ADR со статусом «заменяет ADR-NNNN», а не молчаливое
  расхождение кода и документа.

**7. Что открылось.** Посмотри волны в `docs/tickets/INDEX.md`: какие тикеты разблокированы
этим слиянием. Перед следующим тикетом — `/clear`.

## Чего не делать

- Не сливать ветку с красными тестами «чтобы не блокировать волну» — блокировка честнее.
- Не откладывать уборку worktree: через три тикета никто не помнит, что в `/d/orbita-wt`
  можно удалять.
- Не оставлять ветку висеть после слияния: следующий агент возьмёт её за основу.
